## 📌 Project Overview

This repository contains multiple beginner-to-intermediate Python programming assignments created for learning and practicing core Python concepts.

The project includes:

- Python basics
- Variables and data types
- Conditional statements
- Loops
- Functions
- List, Tuple, Set, Dictionary
- File handling
- Excel file operations
- Pattern printing
- Problem-solving exercises
